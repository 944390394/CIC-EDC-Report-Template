# CIC 工作室专用｜电子设计竞赛 LaTeX 报告模板

## 简介
面向武汉职业技术大学 CIC 工作室的中文 LaTeX 报告模板（可扩展至同类科创赛事）。  
目标是帮助工作室队伍快速搭建规范文档结构，把时间投入到方案与数据本身。

---

## 模板定位

- 这是一个**通用写作模板**，不是某个具体项目的报告成稿。
- 本模板当前为 **CIC 工作室专用版本**，用于统一内部文档风格与交付规范。
- 模板保留完整章节骨架，并提供“怎么写”的提示与占位符。
- 使用者只需替换内容、图片和数据，即可生成可提交的报告版本。

## 模板亮点

- 完整章节：题目、摘要、目录、方案设计、理论分析、电路与程序、测试结果、结论、参考文献、附录。
- 中文友好：基于 `ctexart`，兼容常见中文排版场景。
- 注释引导：关键章节附带写作提醒，适合新手按评分点填充。
- 图表公式支持：内置图片、三线表、公式、代码块样式。
- 可维护：适合社团/实验室长期复用并持续迭代。

## 使用流程（3 步）

### 1) 环境准备

安装任一 LaTeX 发行版：

- [TeX Live](https://www.tug.org/texlive/)（Windows / Linux / macOS）
- [MiKTeX](https://miktex.org/)（Windows）
- [MacTeX](https://www.tug.org/mactex/)（macOS）

推荐编辑器（任选）：

- VS Code + LaTeX Workshop
- TeXstudio
- TeXworks

### 2) 内容替换

1. 将图片统一放到 `pic/`（框图、电路图、流程图、实物图等）。
2. 打开 `src/Template.tex`，按章节提示替换占位符。
3. 将“示例文本”替换为真实项目内容，删除提示语和演示注释。
4. 检查图、表、公式、参考文献是否都被正文引用。

插图示例：

```tex
\includegraphics[width=0.8\linewidth]{../pic/your-image.png}
```

### 3) 编译生成 PDF

在 `src/` 目录编译 `Template.tex`。

建议引擎：

- `pdfLaTeX`（模板已兼容）
- `XeLaTeX`

说明：

- 使用 `XeLaTeX`：可自定义中文字体。
- 使用 `pdfLaTeX`：不需要 `\setCJKmainfont`。

## 写作规范建议

- 摘要控制在赛题要求范围内（常见要求为 300 字以内），关键词建议 3-5 个。
- 方案比较建议至少给出 2 个备选方案，写清优缺点和最终选择依据。
- 理论与参数计算要和测试指标一一对应，避免“只讲原理不落到指标”。
- 测试数据建议多次测量，给出理论值、实测值、误差或是否达标。
- 结论建议分为“已达到指标”和“未达到指标及原因分析”两部分。
- 参考文献若使用，必须在正文中有对应引用，编号顺序按首次出现排序。

## 常见问题（FAQ）

### Q1: 报错 `Undefined control sequence \setCJKmainfont`

原因：`pdfLaTeX` 下不支持该命令。  
处理：改用 `XeLaTeX`，或在 `pdfLaTeX` 条件下禁用该命令。

### Q2: 附录如何单独起页

在附录前加入：

```tex
\newpage
\appendix
```

### Q3: 参考文献怎么写上标引用

两种常见方式：

- 手动上标：`\textsuperscript{[1]}`
- 自动引用：`\cite{ref1}`（推荐）

### Q4: 模板里的示例内容要不要保留

不建议保留。提交前应删除示例语句与提示注释，只保留项目真实内容。
